# Astroverse

Локальный интерактивный 3D-планетарий: Солнечная система → окрестности Солнца → Млечный Путь.

## Возможности v0.3

- Солнечная система с процедурными текстурами планет и крупных спутников, атмосферами, кольцами, поясом астероидов и поясом Койпера
- Каталог из 70+ тел: планеты, карликовые планеты, луны, близкие и яркие звёзды, экзопланеты, туманности, скопления, чёрные дыры и галактики-соседи
- Карточки с описанием, спектральным классом, массой, температурой, периодом и источником
- Окрестности Солнца: звёзды по приближённым экваториальным координатам
- Млечный Путь как пересечённая спираль: балдж, перемычка, четыре рукава, Orion Spur, пыль и положение Солнца
- Поиск по имени, описанию и фактам

## Запуск одной командой (Docker)

Нужен Docker Desktop / Docker Compose.

```bash
docker compose up --build
```

Открыть: http://localhost:5173

Остановка: `Ctrl+C`, затем при необходимости `docker compose down`.

## Запуск на macOS без Docker

Нужны Python 3.10+ и Node.js 18+.

### Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

### Frontend (в другом терминале)

```bash
cd frontend
npm install
npm run dev
```

Открыть: http://localhost:5173

Каталог лежит в `data/objects.json`. Пересобрать его после правок `data/build_catalog.py`:

```bash
python3 data/build_catalog.py
```

## Архитектура

```text
Astroverse
├── frontend  React + Three.js + Vite
├── backend   FastAPI
└── data      JSON-каталог объектов
```

Масштабы визуализации сжаты (иначе Юпитер и галактика не умещаются в одном кадре). Числа в карточках — справочные, по NASA / Gaia / IAU.
